### ASP

#### Clingo learning sequence

1. Read Vladimir Lifschitz's [Answer Set Programming](https://www.cs.utexas.edu/~vl/teaching/378/ASP.pdf):
   - Chapters 1-3 for ASP concepts, Clingo constructs, and computational problems.
   - Chapter 6 for additional language constructs.
   - Chapter 7 for actions, state transitions, and planning.
   - Initially skip the more mathematical chapters if they slow down practical progress.
2. Work through Potassco's [Answer Set Solving in Practice](https://teaching.potassco.org/) course:
   - [Introduction](https://teaching.potassco.org/introduction/) for stable models, variables, and safety.
   - [Modeling](https://teaching.potassco.org/modeling/) for workflow, choices, constraints, case studies, and planning.
   - [Grounding](https://teaching.potassco.org/grounding/) for rule instantiation and the grounding process.
   - [Encoding](https://teaching.potassco.org/encoding/) for alternative encodings and performance.
3. Study the [Towers of Hanoi Quickstart](https://potassco.org/guide/quickstart/) line by line as a complete Generate-Define-Test-Display planning example.
4. Reinforce each topic by implementing small local demos before moving to a larger model.
5. Use the [Clingo Input Language](https://potassco.org/guide/language/) guide as a syntax reference rather than reading it sequentially.

```text
Lifschitz book       -> learn the ideas
Potassco course      -> learn modeling through examples
Small local demos    -> make the ideas stick
Language guide       -> look up exact syntax
```
